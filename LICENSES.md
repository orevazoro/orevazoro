# Third-party assets embedded in these SVGs

All SVGs are self-contained: fonts and icons are embedded inline, and nothing is loaded from the network.

## Fonts (SIL Open Font License 1.1, embedded as subsetted base64 WOFF2)
| Font | Role | Source |
|---|---|---|
| Bebas Neue (Ryoichi Tsunekawa / Dharma Type) | Display | https://fontsource.org/fonts/bebas-neue |
| Barlow 400 and 600 (Jeremy Tribby) | Body | https://fontsource.org/fonts/barlow |
| JetBrains Mono 400 (JetBrains) | Mono | https://fontsource.org/fonts/jetbrains-mono |

The fonts were subset to Basic Latin plus a few punctuation marks. Full OFL 1.1 text: https://openfontlicense.org

## Icons (Simple Icons v13.21.0, CC0 1.0)
Source: https://simpleicons.org (npm package `simple-icons@13.21.0`).
Python, OpenJDK (used for "Java"), JavaScript, C, SQLite, FastAPI, Flask, Ollama, NumPy, Pandas, Git, Linux, Figma, LinkedIn, Instagram, GitHub.
Icons whose official colour is too dark for a navy background were recoloured: Flask, Ollama and GitHub (white), NumPy, Pandas, SQLite (lighter tints of their brand colours). Java uses the Java orange.
The brand marks remain trademarks of their respective owners.

## Images
`id.png` and `right_pointing.png` are your own generated character images, embedded at reduced size.
